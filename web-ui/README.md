# Synnical OS - Web UI

The new minimal desktop UI for Synnical OS.

## Features

- 🌸 Cherry Blossom Samurai wallpaper
- ⏰ Live clock widget with date
- 📅 Calendar and notes widgets
- 🖥️ Dock with real app icons
- 🔍 App launcher with search
- ✨ Glassmorphism design

## Setup

```bash
npm install
npm run dev
```

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
